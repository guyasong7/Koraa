# Electronics Store Pro Template

A professional, modern template designed specifically for electronics and technology stores on Koraa.

## Features

✨ **Modern Design**
- Clean, tech-focused aesthetics
- Gradient accents and smooth animations
- Professional product presentation

🌓 **Dark Mode Support**
- Toggle between light and dark themes
- Optimized for both viewing preferences
- Smooth theme transitions

📱 **Fully Responsive**
- Mobile-first design
- Tablet and desktop optimized
- Touch-friendly interactions

🔍 **Advanced Search**
- Real-time product search
- Category filtering
- Specifications filtering

🛒 **Shopping Features**
- Shopping cart with live badge
- Wishlist functionality
- Product comparison

🎨 **Customizable**
- Brand color theming
- Typography options
- Layout configurations

## Installation

```bash
npm install
```

## Usage with Koraa

This template is built using the official Koraa Storefront SDK. It automatically integrates with your Koraa store data:

- Store information (name, logo, colors)
- Product catalog
- Cart functionality
- Order processing

## Customization

The template includes configuration options:

```typescript
config: {
  colors: {
    primary: '#0066FF',    // Main brand color
    secondary: '#1A1A1A',  // Secondary color
    accent: '#00E5FF'      // Accent color
  },
  layout: {
    maxWidth: '1400px',
    gridColumns: 4,
    productCardStyle: 'modern',
    showSpecs: true
  }
}
```
